# EnglishAI - Aprenda Inglês com IA

Aplicativo para aprender inglês conversando com inteligência artificial (Google Gemini).

## Como usar

1. Abra `index.html` no navegador
2. Crie uma conta
3. Insira sua chave de API do Google Gemini (gratuita em https://aistudio.google.com/apikey)
4. Comece a praticar!

## Funcionalidades

- Chat com IA que adapta o inglês ao seu nível (A1-C2)
- Sistema de progressão automática
- Exercícios gerados por IA
- Flashcards por nível
- Dashboard de progresso com XP e conquistas
- Funciona no celular como app (PWA)

## Tecnologias

- HTML5 + CSS3 + JavaScript
- Tailwind CSS
- Google Gemini API
- PWA (Progressive Web App)
